# AI usage declaration

Cursor was used as an AI pair-programmer on this project.

The main model was **Claude Sonnet 4.6**. **Claude Opus 4.6** was used for validation logic and for integration debugging when modules needed to work together.

AI help covered scaffolding, CRUD logic, validation, and styling across all four modules:

1. Help Requests
2. Resource Offers
3. Shelters
4. Dashboard

Typical work included setting up routes and models, wiring create/read/update/delete flows, shared form and phone/district checks, connecting the React client to the Express API, and applying consistent layout and CSS.

People on the team reviewed the generated code, ran the app, and adjusted it to match the assignment. This file is the mandatory AI usage declaration for the project.
